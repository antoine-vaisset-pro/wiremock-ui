# Contributing

Thank you for contributing to WireMock UI!

1. Fork the repository and create a focused branch.
2. Install dependencies with `make install`.
3. Make the change and add or update tests.
4. Run `npm run lint` and `npm run test` in `src/main/webapp`.
5. Commit using [Conventional Commits](https://www.conventionalcommits.org/), for example `fix: handle empty backend configuration`.
6. Open a pull request describing the behavior and verification.

Contributions are accepted under the Apache License 2.0, including the terms in Section 5 (Submission of Contributions).
